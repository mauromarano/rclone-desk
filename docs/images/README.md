# Original Rclone Desk image assets

The Rclone Desk mark is original geometry authored for this project: two rounded file panes in ink `#172033` and action blue `#2459D6`, joined by a directional connector. It uses no provider logos, wordmarks, icons, or other third-party brand artwork. The social preview is a composed interface illustration built from the same shapes and colors, not a product screenshot.

- `../../frontend/public/favicon.svg` is the scalable browser icon.
- `../../frontend/public/images/rclone-desk-mark.svg` is the sidebar mark.
- `rclone-desk-mark-inverse.svg` is the inverse for dark backgrounds.
- `social-preview.svg` is a 1280 × 640 share preview.

The PNG variants were rasterized from these original SVGs using Chromium via Playwright 1.56.0. `frontend/public` includes 16/32 px favicon PNGs and ICO, a 180 px touch icon, and 192/512 px app icons. `social-preview.png` is the 1280 × 640 raster share image. No image model or third-party artwork was used. All original brand assets are included under this repository's MIT license; no trademark registration or official rclone affiliation is claimed.

`desktop.png` and `mobile.png` show the application with synthetic demo remotes and files, created in a temporary container without cloud credentials. They are documentation captures, not evidence of live cloud-provider connectivity.
