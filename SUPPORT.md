# Support

Rclone Desk is an experimental community project. Start with the [README](README.md), [deployment guide](docs/deployment.md), and [backup guide](docs/backup.md).

For a usage question or reproducible bug, open an issue in the repository hosting this source, if issue tracking is enabled. Include the app version/commit, Docker and Compose versions, a sanitized description of the setup, and steps to reproduce. Remove credentials, tokens, private file paths, remote listings, and sensitive log lines before posting.

For a suspected security vulnerability, do not open a public issue. Follow the private reporting instructions in [SECURITY.md](SECURITY.md). Support is community-based and has no response-time guarantee.
